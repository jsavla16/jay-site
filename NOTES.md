# Notes — building jay-shah-site

Raw material for the blog. Written as things happen. The habit: when
something breaks and gets fixed, add an entry — what happened, what it
looked like, what it actually was, what it cost. Five lines is enough. The
polished version comes later.

---

## No registry access in the build sandbox

**What happened.** Scaffolding the site with `create-next-app` failed
immediately.

**What it looked like.** `npm error 403 403 Forbidden` on every package —
`create-next-app`, then `next` installed directly, same result.

**What it actually was.** The agent sandbox's outbound network is
allowlisted, and `registry.npmjs.org` isn't on it —
`X-Proxy-Error: blocked-by-allowlist`, confirmed with `curl -I`. Not a
registry outage: unpkg, jsdelivr, and raw GitHub were blocked the same way.

**The fix.** No `npm install` inside the sandbox. Every file
(`package.json`, `app/`, `lib/`, config) written by hand instead of
generated by the CLI, then handed off — dependencies get installed and the
build gets verified on the user's own machine and again by Vercel at
deploy time.

> A tool that can write files but can't reach the internet still has to
> produce something installable — it just can't confirm it installs.
